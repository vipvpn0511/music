# MusicFlow — موزیک پلیر شیشه‌ای

نسخه اول یک موزیک پلیر فارسی با طراحی Glassmorphism است. پروژه برای GitHub Pages و نصب به شکل PWA آماده شده است.

## امکانات فعلی
- رابط واکنش‌گرا و راست‌چین با پنل‌های شیشه‌ای
- انتخاب چند فایل صوتی از گوشی و پخش MP3/WAV/M4A و فرمت‌های پشتیبانی‌شده توسط مرورگر
- لیست آهنگ‌ها، جست‌وجو و فیلتر علاقه‌مندی‌ها
- پخش/توقف، قبلی/بعدی، پخش تصادفی، تکرار و تنظیم بلندی صدا
- تایمر خواب و تغییر تم روشن/تیره
- فایل manifest و Service Worker برای نصب PWA و کش کردن پوسته برنامه

## انتشار رایگان در GitHub Pages
1. وارد GitHub شو و یک مخزن **Public** جدید بساز؛ مثلاً `musicflow`.
2. فایل‌های داخل ZIP را در ریشه مخزن بارگذاری کن (خود پوشه `musicflow-pwa` را داخل مخزن نگذار؛ فایل‌هایش باید مستقیم در ریشه باشند).
3. در مخزن به **Settings → Pages** برو.
4. در بخش Build and deployment، گزینه **Deploy from a branch** را انتخاب کن.
5. شاخه `main` و پوشه `/(root)` را انتخاب و Save کن.
6. پس از آماده شدن انتشار، نشانی شبیه `https://USERNAME.github.io/musicflow/` را باز کن.
7. در Chrome اندروید، منوی سه‌نقطه را باز کن و **Install app** یا **Add to Home screen** را بزن.

## نکات مهم
- برای کارکرد Service Worker و نصب PWA، برنامه باید از HTTPS (مثل GitHub Pages) باز شود؛ باز کردن مستقیم `index.html` از فایل‌منیجر همه قابلیت‌ها را فعال نمی‌کند.
- مرورگرها اجازه نمی‌دهند سایت بدون اجازه کاربر کل حافظه گوشی را اسکن کند؛ کاربر باید فایل‌های صوتی را خودش انتخاب کند.
- در این نسخه، فایل‌های صوتی از انتخاب فعلی مرورگر پخش می‌شوند و برای حفظ حریم خصوصی به سرور آپلود نمی‌شوند. ممکن است پس از بستن کامل برنامه لازم باشد دوباره فایل‌ها را انتخاب کنی.
- پخش در پس‌زمینه و کنترل کامل از صفحه قفل بسته به مرورگر و سیستم‌عامل محدود است؛ برای تجربه بومی و قابل‌اعتماد باید در مرحله بعد APK واقعی با پشتیبانی MediaSession/سرویس اندروید ساخته شود.
- این پروژه فعلاً از فایل‌های محلی استفاده می‌کند؛ کاتالوگ موسیقی آنلاین یا متن آهنگ بدون اتصال به منبع مجاز اضافه نشده است.

## ساخت APK
GitHub Pages خودش فایل APK تولید نمی‌کند. پس از تست PWA، برای APK از یک روش بسته‌بندی معتبر مانند Bubblewrap/TWA (با دامنه HTTPS تأییدشده و تنظیمات Digital Asset Links) یا پروژه اندرویدی بومی استفاده کن. APK باید با کلید معتبر امضا شود؛ ZIP این پروژه APK نیست.
